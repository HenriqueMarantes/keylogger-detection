# Keylogger Detection Tool

This project is a basic Python tool designed to detect suspicious processes that may indicate keylogger activity.

---

## Features
- Scans running processes  
- Detects suspicious keywords (e.g., keylog, logger, hook)  
- Identifies potential malicious behavior  

---

## How It Works

The script uses the `psutil` library to:
- List all running processes  
- Analyze process names  
- Flag potentially suspicious processes  

---

## Requirements

- Python 3  
- psutil
